# Sales Forecasting System

This is a major data science project based on sales forecasting using machine learning and time series analysis.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Features
- Sales trend analysis
- Monthly sales forecasting
- Data visualization
- Machine learning prediction

## Dataset
Superstore sales dataset containing:
- Order Date
- Sales
- Profit
- Category
- Region

## Project Structure
- data/ → dataset
- src/ → Python code
- outputs/ → generated graphs

## Objective
To predict future sales trends using historical sales data.
